How to Add Images

Since Firebase free tier doesn't allow image storage, use these free image hosting services:

Option 1: ImgBB (Recommended)

  1. Go to imgbb.com
  2. Click "Start uploading" and select your image
  3. After upload, click on the image
  4. Copy the "Direct link" URL (ends with .jpg/.png)
  5. Paste that URL in the Image URL field

Option 2: Google Drive

  1. Upload image to Google Drive
  2. Right-click > Share > "Anyone with the link"
  3. Copy the link (looks like: drive.google.com/file/d/FILE_ID/view)
  4. Replace the URL format to: https://drive.google.com/uc?export=view&id=FILE_ID

Option 3: Local Images

  1. Save your image in the images/ folder of your website
  2. Use the path: images/your-image-name.jpg
  3. This is the fastest option but requires FTP/server access

Tip: For best results, use square images (1:1 ratio) with minimum 300x300 pixels. Compress large images before uploading for faster loading.
